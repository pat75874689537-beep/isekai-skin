ตั้งค่าแอดออน

ไอดีไอเทมจะเป็น ชื่อย่อ:รหัส • ตั้งให้ไม่ซ้ำกับแอดออนอื่นในเซิร์ฟ กันไอเทมชนกัน • เปลี่ยนแล้วไอเทมเดิมในโลกจะหาย

ค่าเกราะเป็น 0 เสมอ (ของแต่งตัว) • สร้างซ้ำได้แพ็กเดิมเวอร์ชันใหม่ นำเข้าทับของเก่าได้

ใช้เมื่อแตะไฟล์แล้วเกมเปิดแต่ไม่มีข้อความนำเข้าขึ้นเลย • ไอเทมจะได้ไอดีใหม่ ของเก่าที่แจกในโลกไปแล้วต้องแจกใหม่

สร้างแอดออน

ไอเทมที่จะได้ในเกม (ไอคอนแบบในกระเป๋า) • แตะ "ก๊อป" เพื่อเอาคำสั่งไปแจกในเกม

เปลี่ยนไฟล์ .zip เป็น .mcaddon

หน้าเว็บส่งไฟล์ออกมาเป็น .zip ได้อย่างเดียว เปลี่ยนนามสกุลก่อนเปิดด้วยมายคราฟ

  • Android: แอปไฟล์ → Download → กดค้างที่ไฟล์ → เปลี่ยนชื่อ → แก้ .zip เป็น .mcaddon → แตะเปิดด้วย Minecraft
  • iPhone: แอป ไฟล์ → กดค้างที่ไฟล์ → เปลี่ยนชื่อ → แก้ท้ายเป็น .mcaddon → แตะ → แชร์ → Minecraft
  • Windows: File Explorer → View → ติ๊ก File name extensions → คลิกขวา → Rename → .mcaddon → ดับเบิลคลิก
เปิดไฟล์เข้าเกม
  • Android: แตะแจ้งเตือนดาวน์โหลด หรือแอปไฟล์ → Download → แตะไฟล์ .mcaddon → เลือก Minecraft
  • iPhone: แอป ไฟล์ → ดาวน์โหลด → แตะไฟล์ → แชร์ → Minecraft
  • Windows: ดับเบิลคลิกไฟล์ในโฟลเดอร์ Downloads

ชื่อไฟล์เป็นภาษาอังกฤษเสมอ (เช่น ISEKAI_v3.mcaddon) ส่วนชื่อแพ็กในเกมยังเป็นภาษาไทยตามที่ตั้ง • ถ้าจะเปลี่ยนชื่อไฟล์เอง ห้ามมีภาษาไทยหรือเว้นวรรค ไม่งั้นเกมจะเปิดขึ้นมาแต่ไม่นำเข้า • ถ้าเครื่องเปลี่ยนเป็น .zip เอง ให้แก้กลับเป็น .mcaddon

ใช้เป็นสกินหลักในเกม: ห้องแต่งตัว → สกินคลาสสิก → นำเข้า → เลือกไฟล์นี้ → แบบแขนปกติ • ทำครั้งเดียวพอ

แก้ปัญหาที่เจอบ่อย
แตะไฟล์แล้วเกมเปิด แต่ไม่มีข้อความนำเข้าขึ้นเลย
1) ชื่อไฟล์มีภาษาไทยหรือเว้นวรรค → เปลี่ยนเป็นอังกฤษล้วน เช่น isekai_v3.mcaddon
2) ชื่ออังกฤษแล้วยังเงียบ = ไอดีแพ็กชนกับที่อยู่ในเกม → กด ขอไอดีแพ็กใหม่ ในขั้นตั้งค่า แล้วสร้างใหม่
แตะไฟล์แล้วไม่มี Minecraft ให้เลือก
ไฟล์อาจกลายเป็น .zip → เปลี่ยนนามสกุลกลับเป็น .mcaddon
ขึ้นว่าแพ็กซ้ำ / นำเข้าทับไม่ได้
เวอร์ชันเท่าเดิมกับที่เคยนำเข้า → เพิ่มเลขเวอร์ชันในขั้นตั้งค่าแล้วสร้างใหม่
หาไอเทมไม่เจอ
เปิด Behavior Pack ในการตั้งค่าโลกหรือยัง → ดูในแท็บอุปกรณ์ กลุ่มเกราะของช่องที่เลือก หรือใช้คำสั่ง /give จากรายการด้านบน
สวมแล้วไม่เห็นสกิน
มุมมองบุคคลที่ 1 จะไม่แสดง (ตั้งใจ ไม่บังจอ) → สลับเป็นบุคคลที่ 3 • ต้องสวมในช่องเกราะที่เลือกตอนสร้าง ไม่ใช่ถือในมือ
เห็นสกินเดิมของตัวเองซ้อนอยู่
ยังไม่ได้ใช้สกินล่องหน → กดปุ่มโหลดสกินล่องหนด้านบน แล้วนำเข้าเป็นสกินหลัก
ผมหรือชิ้นตกแต่งไปอยู่ผิดที่
ปรับตำแหน่ง/มุม/ส่วนที่ติดได้ในหมวด ชิ้นพิเศษ ใต้ตัวอย่าง 3 มิติ • ถ้าสกินมาคู่กับ .bbmodel ใส่ไฟล์นั้นในขั้นที่ 1 ด้วย
มองทะลุตัวเป็นรู ๆ
ลายสกินชั้นในมีจุดโปร่งใส → แก้รูปสกินให้ทึบ (เว็บจะเตือนในรายการสกินถ้าเจอ)
เข้าเกมแล้วใช้ยังไง
  1. ใช้ สกินล่องหน เป็นสกินหลักของตัวเอง (กดปุ่มโหลดด้านบน)
  2. สร้างหรือแก้โลก → เปิด Behavior Pack (Resource Pack เปิดตามเอง)
  3. โหมดสร้างสรรค์ → แท็บอุปกรณ์ → กลุ่มเกราะของช่องที่เลือก → หาไอเทมหน้าหัวสกิน
  4. สวมในช่องเกราะ = เห็นสกิน • ถือในมือหรือมุมมองบุคคลที่ 1 จะไม่วาด
  5. เอาชีวิตรอด: แจกด้วย /give @s ชื่อไอเทม (ดูชื่อใน README.txt ในแพ็ก)

รวมแอดออน

รวมไฟล์ .mcaddon ที่สร้างจากเว็บนี้หลายไฟล์ให้เป็นแพ็กเดียว • ไอดีไอเทมเดิมครบทุกชิ้น ของที่แจกในโลกไปแล้วไม่หาย

หลังรวมแล้วต้องทำอะไร
  1. นำเข้าไฟล์รวมเข้าเกม
  2. ในโลก: ปิดแพ็กเดิมที่รวมไปแล้วออก (ไม่งั้นไอเทมจะซ้ำกัน) แล้วเปิดแพ็กรวมแทน
  3. จะเพิ่มอีกทีหลัง: ใส่ ไฟล์รวมเดิม + ไฟล์ใหม่ → ได้แพ็กรวมเดิมเวอร์ชันใหม่ นำเข้าทับได้เลย
ISEKAIทุกอย่างทำในเครื่องคุณเอง ไม่มีการอัปโหลดสกินไปที่ไหน
